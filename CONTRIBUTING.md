# Contributing

Short version: **this project doesn't accept outside contributions.**

It's a personal tool, published so others can read it, learn from it, and build
their own version. It is not run as a community project, and I don't have the
bandwidth to review, maintain, or support code I didn't write.

## What you're welcome to do

- **Clone it.** `git clone https://github.com/geidsvig/vscode-ai-agents.git`
- **Read it.** The whole extension is a handful of plain `.js` files, no build step.
- **Fork it.** Take it in whatever direction you like — the MIT license (see
  [LICENSE](LICENSE)) covers you. You don't need to ask.

## What won't be accepted

- **Pull requests.** Non-collaborators are blocked from opening them, and any
  that do get through will be closed unread. Please don't spend the effort.
- **Issues and feature requests.** The issue tracker is turned off on purpose.

None of this is personal — a fork is genuinely the right answer here. If this
extension is 80% of what you want, the remaining 20% is yours to write, and
you'll get there faster than waiting on me.

## Security

If you've found something with security impact, that's the one exception. Please
report it privately rather than publicly: open a
[security advisory](https://github.com/geidsvig/vscode-ai-agents/security/advisories/new).
